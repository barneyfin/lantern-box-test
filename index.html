Test builds of Gloam Hallow and the kit's test page, for trying on any device. Not finished, and not for sharing.

Kit version: checking…

On a phone

  • Hold it sideways.
  • For full screen on an iPhone, open Gloam Hallow, then Share, then Add to Home Screen, and play it from its icon. An iPhone won't let a web page fill the screen, so its full-screen button tells you this.

The play check

  • Tap Play check, then Start game, and leave it be: it plays by itself, and keeps the screen awake. When it finishes, copy the result.
  • It is the same as Settings, Testing, Play check in the game.

The speed check

  • Open the test page and tap Speed check (or press T). When it finishes, copy the line it gives you.
  • On a slow device, also tap Parts check: about a minute, timing each part of the picture on its own. Copy its line too.

After an update

  • The kit version above is read fresh from the server each time. GitHub lets a phone keep a page for up to 10 minutes, so the links below it carry the version, and open the new files as soon as they are up.
  • On an iPhone, remove the old Home Screen icon and add it again from the link here, so it opens the new version.
